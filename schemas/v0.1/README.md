# PUI89 Shared AI Core schema snapshot — v0.1.0

Read-only compatibility snapshot from [PUI89/PUI89-Shared-AI-Core](https://github.com/Pui89/PUI89-Shared-AI-Core), source commit `d7c16d0aee589349cd70b86bffaae531415c00cd` (main, 2026-11-09).

The Shared AI Core is private; public GitHub Actions cannot check it out using the default repository token. This snapshot lets CI validate against the pinned contract without exposing credentials or making the Core public. It contains schemas only, not shared implementation code.

Do not edit these files independently. Update them from a reviewed Core release and record the source commit. The schemas declare JSON Schema Draft 2020-12; the Core's lightweight Python validator supports only its documented subset and is not a full Draft 2020-12 validator.

ActionProposal is advisory-only, requires human approval, and never authorises physical actuation.
